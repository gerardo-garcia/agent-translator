# Model table sources

`catalog_data.py` is generated by `scripts/gen_model_catalog.py` from the model catalog of
[BerriAI/litellm](https://github.com/BerriAI/litellm) (`model_prices_and_context_window.json`,
MIT license outside its `enterprise/` directory), commit recorded in `LITELLM_COMMIT`. That file
lists, per provider, the model ids that provider accepts (Anthropic API, AWS Bedrock Converse,
Vertex AI, OpenAI, Azure, Gemini API). Only the ids we need are copied; the snapshot is not
redistributed.

Our own rules on top of it: which families are included (GPT-4o/4.1/5.x, Gemini pro/flash/
flash-lite, Claude, Nova, Llama, Mistral on Bedrock), the size **tier** of each (large / medium /
small, by model name), merging dated and undated Claude ids into one family, and dropping the
one entry known to be wrong (`anthropic.claude-3-7-sonnet-20240620-v1:0`; the real date is
20250219). Tiers are a judgement, not a benchmark: use `-O model_policy=tier` knowingly.

To refresh: download the catalog at a newer commit and rerun the script, then the tests.
